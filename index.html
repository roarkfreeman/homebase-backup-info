HomeBase Backup Pilot

A personal, owner-only backup utility using rclone.

After its owner authorizes Google Drive access, the utility reads file content and metadata to copy owner-selected HomeBase data through the owner's PC into the owner's pCloud account.

This public website provides information only. Visitors cannot sign up, access backed-up files, or use the backup utility. The pilot is being configured; this page does not claim that a complete backup is already operational.
